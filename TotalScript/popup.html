Getting started
  1. Run bin/total-core.exe and leave it open
  2. Open Roblox Studio and switch on Assistant → ⋯ → Manage MCP Servers → Studio as MCP server
  3. Open a place (File → New → Baseplate works)
  4. Open any supported AI chat and press ▶ Start Agent on the TotalScript bar

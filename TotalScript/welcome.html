Hello! TotalScript is installed.

Thanks for installing. You describe what you want in plain words on any supported AI site, and TotalScript builds, scripts, tests and screenshots it inside Roblox Studio. Four quick steps and you are building:

  1. 1
    Run the agent appIn your TotalScript folder, start bin/total-core.exe and leave it open. It links the chat to Studio and keeps running in the background.
  2. 2
    Link Roblox StudioIn Studio open the Assistant panel → ⋯ → Manage MCP Servers → turn on Studio as MCP server. Once per Studio install.
  3. 3
    Open a placeAny place works — File → New → Baseplate is fine for a first try.
  4. 4
    Open an AI chat and press Start AgentThe TotalScript bar sits above the chat box. Settings → Help has the full tutorial and a live setup checklist any time.

This hello page is shown once, right after installation. You can always find the same steps under the extension icon and in the bar's Settings → Help.
